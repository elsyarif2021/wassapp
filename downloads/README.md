# WassApp Android 0.2.0 (debug)

Buka `WassApp-0.2.0-debug.apk`, lalu pilih **Download raw file** untuk mengunduh.
Berkas ini adalah APK lokal yang sudah dibangun dan diverifikasi tanda tangannya,
bukan hasil GitHub Actions yang belum terpantau. SHA-256 tersedia di file pendamping.

Minimum Android 7.0. Ini build debug untuk pengujian. Instalasi memerlukan izin
memasang aplikasi dari sumber ini. Jika sebelumnya memasang build dari GitHub
Actions dengan tanda tangan berbeda, update dapat ditolak; jangan menghapus aplikasi
lama sebelum memastikan tidak ada data lokal yang perlu dipertahankan.

Login/chat online memerlukan aktivasi Supabase sesuai `../ONLINE-SETUP.md`.
